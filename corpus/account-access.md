# Account access

Fictional DeskFlow documentation. Synthetic learning material, not a real service.

## Account recovery

Para recuperar acceso a tu cuenta, solicita un enlace de recuperación.
El error AUTH_042 indica que el enlace venció. Solicita uno nuevo; no reutilices
el enlace anterior. Nunca compartas tu contraseña con soporte.

## Session access

Para revisar el acceso de tu equipo, abre la lista de sesiones activas.
Cierra las sesiones que no reconozcas.
